# Lesson QR Codes

These QR images route the printed story lessons into the matching interactive tutorial:

- `QR_Bevel.png` → `arlearning://tutorial/bevel`
- `QR_Extrude.png` → `arlearning://tutorial/extrude`
- `QR_Inset.png` → `arlearning://tutorial/inset`
- `QR_Knife.png` → `arlearning://tutorial/knife`
- `QR_LoopCut.png` → `arlearning://tutorial/loop-cut`

Keep the white quiet zone intact when placing these images in print layouts.
